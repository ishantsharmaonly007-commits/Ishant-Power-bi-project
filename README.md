# 🛒 E-Commerce Sales & Performance Dashboard

## 📌 Project Overview

The **E-Commerce Sales & Performance Dashboard** is a data analytics and visualization project designed to analyze e-commerce business performance through interactive charts, KPIs, and visual insights.

The dashboard helps users understand **sales, profit, orders, customers, product performance, regional performance, and shipping trends** in an easy-to-understand visual format.

---

## 🎯 Objectives

* Analyze overall e-commerce sales performance.
* Track important business KPIs.
* Identify top-performing products and categories.
* Analyze monthly sales trends.
* Compare profit across different regions.
* Understand customer and order distribution.
* Analyze different shipping modes.
* Present business insights using an interactive dashboard.

---

## 📊 Dashboard Features

### 🔹 KPI Cards

The dashboard provides key performance indicators such as:

* 💰 **Total Sales**
* 📈 **Total Profit**
* 🛍️ **Total Orders**
* 👥 **Total Customers**

### 🔹 Visualizations

The dashboard includes:

1. **Monthly Sales Trend**

   * Line chart showing sales performance over time.

2. **Sales by Category**

   * Donut chart representing the contribution of different product categories.

3. **Profit by Region**

   * Horizontal bar chart comparing profit across regions.

4. **Top Performing Products**

   * Column chart showing products with the highest sales/performance.

5. **Ship Mode Distribution**

   * Pie chart displaying the distribution of different shipping methods.
